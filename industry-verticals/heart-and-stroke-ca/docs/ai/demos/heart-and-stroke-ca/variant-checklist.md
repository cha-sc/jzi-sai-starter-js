# Heart and Stroke CA — variant selection checklist

Variants cannot be set via the Marketer Agent API. In Pages editor, open Home and set each component’s variant:

| Section | Component | Instance hint (datasource) | Variant |
|---------|-----------|----------------------------|---------|
| Header | Header | Partial design / layout | `HeaderDarkDonate` |
| Hero | Hero | HeartAndStrokeCA - Hero | `HeroFullBleedPills` |
| Key priorities | Three Column CTA | HeartAndStrokeCA - Key Priorities | `PrioritiesCarousel` |
| Sharon story | Promo CTA | HeartAndStrokeCA - Sharon Story | `StoryOverlayCard` |
| Research | Two Column CTA | HeartAndStrokeCA - Research Stories | `ResearchDualTiles` |
| Get involved | Documents List | HeartAndStrokeCA - Get Involved | `InvolvedLinkList` |
| Ways to give | Two Column CTA | HeartAndStrokeCA - Ways to Give | `GivingPromoTiles` |
| Latest articles | Three Column CTA | HeartAndStrokeCA - Latest Articles | `ArticlesFeatureStack` |
| Recipes | Three Column CTA | HeartAndStrokeCA - Recipes | `RecipesCarousel` |
| Motto | Heading CTA | HeartAndStrokeCA - Motto | `MottoBeat` |
| Newsletter | Contact Form | HeartAndStrokeCA - Newsletter | `NewsletterBand` |
| Footer | Footer | Partial design / layout | `FooterCharcoal` |

For each: select component → Variant dropdown → choose name above → Save.
